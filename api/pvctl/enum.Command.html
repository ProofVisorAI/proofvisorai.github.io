Sidecar

Run the loopback identity sidecar beside an application: it attaches an ProofVisor identity token to every request and forwards it to the gateway, so the application’s SDKs need no code change.

Fields

§config: Option<PathBuf>

Settings file written by the buildpack (gateway, audience, listen, credential). Flags given explicitly override its values.

§audience: Option<String>

Gateway audience [default: $PV_AUDIENCE, then proofvisor].

§listen: Option<SocketAddr>

Loopback address to listen on [default: 127.0.0.1:8485].

§credential: Option<String>

Identity source: cf-instance or token-file:<path> [default: cf-instance].

Pubkey

Print the public key (hex + key_id) derived from an Ed25519 seed file. Use this to pin a trusted public key for pvctl receipt-verify without ever exposing the seed.

Fields

§seed: PathBuf

Seed file (64 hexadecimal characters of raw 32-byte seed, as produced by pvctl keygen).

§

ReceiptLocate

Locate the on-disk audit artifacts for a session id. Spool filenames are sha256(session_id)[..32] — this computes the stem and reports which artifacts (receipt, ATIF trajectory, provenance sidecar, journals, archived prior incarnations) exist for it.

Fields

§session_id: String

The session id exactly as the client sent it.

§spool: PathBuf

ATIF spool directory (atif_spool_dir in the harness config).

§

SpoolPrune

Remove sealed ATIF evidence pairs (.json + .atif-auth, plus their digest-bound .close-complete markers) older than the retention window. Same sweep the harness runs hourly when atif_retention_days is set; run this for one-off reclaims or from external cron when no retention is configured. Unpaired remnants, archived collision evidence, and signed receipts under receipts/ are never touched.

Fields

§spool: PathBuf

ATIF spool directory (atif_spool_dir in the harness config).

§retention_days: u32

Retention window in days; sealed pairs whose mtime is older are removed. 0 prunes every sealed pair immediately.

§

ReceiptVerify

Verify a receipt offline using an independently trusted public key.

Fields

§path: PathBuf

Receipt JSON file.

§public_key_hex: Vec<String>

Trusted Ed25519 public key as 64 hexadecimal characters or standard-alphabet base64 (32 bytes decoded). Repeatable: pass once per key you trust (rotation windows need both the retiring and the incoming key pinned; the receipt’s key_id selects which one verifies it).

JudgeReplay

Replay the semantic judge’s recorded decisions from an embedded Bridge: check that each follows from its verdicts under the configured thresholds, and optionally try other thresholds. Replays thresholds only (not WASM policies that read verdicts) and does not detect tampering: verify the receipts first.

Fields

§data_dir: PathBuf

Embedded Bridge data directory.

§config: PathBuf

Harness configuration whose [judge] thresholds were in force when the records were written.

§what_if: Option<PathBuf>

Another configuration whose [judge] thresholds to try on the same records.

§

JudgeExport

Export the judged calls an embedded Bridge recorded with [judge] record_inputs = true as a labelled set to fill in: one JSON Lines example per predicate, in the format judge-calibrate reads, with an empty label for a reviewer to set and the judge’s own answer in source as a hint. Writes to standard output.

Fields

§data_dir: PathBuf

Embedded Bridge data directory.

§predicate: Option<String>

Only this predicate.

§would_block_only: bool

Only calls the judge would have blocked (shadow mode) or did.

§

JudgeCalibrate

Measure a configured semantic-judge adapter against a labelled set (JSON Lines) and fail when it falls below the given floors.

Fields

§config: PathBuf

Harness configuration holding the [judge] section.

§adapter: String

Name of the [[judge.adapters]] entry to measure.

§set: PathBuf

Labelled set, one JSON example per line.

§min_examples: u64

Fewest examples per predicate.

§min_auroc: f64

Lowest acceptable AUROC, as a probability (0.5 is chance).

§min_separation: f64

Lowest acceptable separation of mean positive-label probability between positive and negative examples.

§max_failure_rate: f64

Largest tolerated share of examples the judge failed to score.

§require_monotone: bool

Require accuracy to rise with confidence.

§min_per_band: u64

Examples a confidence band needs to count in that check.

§tolerance: f64

Allowed accuracy drop between bands, as a probability.

§

ConsoleSync

Upload locally-spooled ProofVisor session evidence to the hosted console.

Fields

§spool_dir: PathBuf

ATIF spool directory (atif_spool_dir in the harness config).

§console_url: Option<String>

Hosted console base URL. Overrides PV_CONSOLE_URL and [console].url.

§deployment: Option<String>

Console deployment id. Overrides PV_CONSOLE_DEPLOYMENT and [console].deployment.

§token_file: Option<PathBuf>

File containing the console ingest token. Overrides PV_CONSOLE_TOKEN and [console].token_file.

§bridge_dir: Option<PathBuf>

Embedded Bridge data directory. Overrides PV_CONSOLE_BRIDGE_DIR and [console].bridge_dir.

§watch: bool

Keep scanning until Ctrl-C.

§interval: u64

Watch polling interval in seconds.

§state_file: Option<PathBuf>

JSON state file recording synced event sequences and receipts.

§dry_run: bool

Print what would be uploaded without contacting the console or updating state.

§pull_policies: bool

Also pull the console’s policy bundle into the daemon’s policy_bundle_file and report what the daemon applied.

§policy_bundle_file: Option<PathBuf>

The daemon’s policy_bundle_file. Overrides PV_POLICY_BUNDLE_FILE.

§

Loadgen

Generate concurrent OpenAI-compatible chat traffic and report latency.

Fields

§url: String

Harness base URL.

§connections: usize

Simultaneous requests. Use 10000 for the deployment SLA.

The 10k figure assumes a Linux host with the listen backlog raised (sysctl net.core.somaxconn=16384 and net.ipv4.tcp_max_syn_backlog=16384). macOS caps the backlog at kern.ipc.somaxconn (default 128), so a 10k simultaneous SYN burst is dropped by the KERNEL before the daemon sees it — the run reports thousands of client-side send errors while the daemon logs nothing. That is the bench box failing, not the daemon: on a stock Mac the same daemon absorbs 4k simultaneous connections with zero drops.

§workflow: String

Signed or unsigned workflow header.

§bearer_token_file: Option<PathBuf>

File containing the NHI bearer token (or PV_BEARER_TOKEN_FILE).
