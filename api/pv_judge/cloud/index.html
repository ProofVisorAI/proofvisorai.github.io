Cloud judge: a generic HTTP contract, proofvisor.judge.v1.

This is a second path by which data leaves the harness (today the harness forwards only the upstream call), so the harness lets each tool opt in separately, applies its redaction engine to the request first, and records the adapter kind in every verdict. It is not any vendor’s API: a vendor is integrated by putting a small translator in front of it, or by the vendor speaking this contract.

Request (POST, application/json):

{"contract":"proofvisor.judge.v1",
 "predicate":{"id":"arg_matches_task@1","labels":["match","mismatch"]},
 "tool":"db_write","arguments":{"table":"orders"},
 "context":{"charter":"billing-agent","delegation_depth":0}}

Response (2xx, application/json, at most 64 KiB):

{"model":{"name":"vendor-judge","version":"2026-10","weights_sha256":"<64 hex>"},
 "probs":[{"label":"match","p":0.18},{"label":"mismatch","p":0.82}]}

The reported model must equal the pin or the call fails as a model mismatch. Redirects are not followed. Errors never include the URL.
