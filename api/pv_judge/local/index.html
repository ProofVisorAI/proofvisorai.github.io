pv_judge

Module local 

Source
Expand description

Local scorer: an ONNX sequence classifier run in-process with tract.

The model and tokenizer files are read once; the SHA-256 of those exact bytes is checked against the pin, and the model is built from the same buffer, so the file cannot change between the check and the load. A mismatch refuses to load (the harness then refuses to start). Unlike the loop breaker’s embedder, an inference error is reported as an error: there is no fallback scorer, because a judge that silently answers with something else would defeat the pin.

Input: the request rendered by crate::render::render_request. Output: one logit per label, in the configured output_labels order; the adapter applies softmax.
