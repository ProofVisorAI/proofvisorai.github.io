A judge backend. Implementations score; they never decide. Policy thresholds turn verdicts into allow, ask, or deny.

fn redact_text(&self, text: &mut String)

Redact text as this adapter redacts arguments before they leave (nothing, for an adapter that sends nothing out). A caller that splits a long text into several requests redacts it whole first, so a secret cut in two cannot slip past patterns that see only one piece.
