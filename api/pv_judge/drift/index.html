Module drift 

Source
Expand description

Runtime calibration check (“drift gate”).

A well-calibrated judge is right more often when it is more confident. The harness samples scored verdicts for human review; reviewers report whether the judge’s most probable label was correct. Accuracy is tracked per confidence band. When accuracy stops rising with confidence (a higher band is less accurate than a lower one by more than the tolerance, each with enough reviews), the predicate is flipped to ask-by-default: judged calls that policy would have allowed are held for approval instead. The flip is sticky until an operator resets it.
