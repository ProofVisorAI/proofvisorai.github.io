Module model 

Source
Expand description

The judge’s data model: model pins, requests, and verdicts.

Probabilities leave the judge as integer parts per million (PPM_ONE = 1.0). Verdicts are written into OCSF events that the session event chain hashes in JCS form, and the signed records in this codebase stay integer-only: a float such as 0.82f32 renders as 0.8199999928474426 and float formatting is where independent JCS implementations disagree. Thresholds use the same unit, so the value an auditor reads in the record is the value the policy compared.
