Crate pv_judge 

Source
Expand description

Semantic judge (action-correctness layer).

Deterministic gates (schema, policy rules, budgets) cannot answer questions such as “do these arguments fit the task this agent was given?”. The judge answers them as probabilities over a fixed label set, and never decides: policy thresholds turn the probabilities into allow, ask, or deny. Every verdict, with its full distribution and the pinned model (name, version, weights SHA-256), is written into the signed audit trail so a decision can be replayed.

Layers:

  • model, predicate, adapter — the data model, the named and versioned predicates, the JudgeAdapter interface and output validation;
  • thresholds — policy thresholds and failure behaviour;
  • record — what goes into the audit trail;
  • drift — the runtime calibration check;
  • runner (feature runner) — deadlines and the concurrency limit;
  • mock, calibration (feature runner) — the test double and the build-time calibration harness;
  • local (feature onnx), cloud (feature cloud) — the backends.
