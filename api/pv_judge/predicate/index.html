Module predicate 

Source
Expand description

Named, versioned predicates with fixed label sets.

A predicate is the question the judge answers (“do these arguments match the task?”). Its id carries a version (name@N) and its label set is fixed for that version, so a policy written against arg_matches_task@1 and its mismatch label keeps meaning the same thing. Changing the labels means a new version.
