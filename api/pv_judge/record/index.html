pv_judge

Module record 

Source
Expand description

The judge record written into the tool-call OCSF event payload and the ATIF tool call’s extra.

For signed workflows the session receipt signs the head of the event chain, which hashes every event in JCS form; for unsigned workflows a retroactive receipt signs the digest of the ATIF trajectory file. Writing this record into both places means every verdict is covered by whichever signature the session ends up with, without changing the receipt format. Every number in it is an integer.
