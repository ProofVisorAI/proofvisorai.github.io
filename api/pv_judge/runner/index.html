Module runner 

Source
Expand description

Runs judge adapters under a hard deadline and a concurrency limit.

Each scoring call runs as its own task that owns a concurrency permit. When the deadline expires the caller stops waiting, but the permit stays held until the backend work actually finishes, so a slow model keeps counting against the limit instead of piling up hidden work. When no permit is free the call is not attempted and comes back as FailureKind::Saturated: backpressure turns into a deny (or ask) for judged tools only, never into a silent allow.
