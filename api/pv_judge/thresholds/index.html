Module thresholds 

Source
Expand description

Policy thresholds: turning verdicts into allow, ask, or deny.

The judge only reports probabilities. The thresholds here belong to policy (they are configured with the policy, not with the model), so the model can be swapped without moving a decision boundary, and an auditor can replay a decision from the record: “the judge gave 0.82 for mismatch, the deny threshold was 0.7, so the call was denied.”

Structs§

FailurePolicy
What policy does when the judge produced no usable verdict. Allow is never accepted: a judge failure must not let a call through silently. A model mismatch always denies.
JudgeDecision
A policy decision over a set of judge outcomes.
ThresholdPolicy
The configured thresholds and failure behaviour.
ThresholdRule
One threshold over one label of one predicate. Comparisons are strict: deny_above_ppm = 700_000 denies at 700_001 and above.
