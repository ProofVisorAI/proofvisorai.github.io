Source
Expand description

Receipts: RFC 8785 (JCS) canonicalization, session event-chain hashing, and Ed25519-signed, offline-verifiable Receipts (brief Module G).

Signing discipline: a Receipt is finalized once, at session close, asynchronously — never per streaming chunk. Verification requires only the receipt JSON and the signer’s public key (or a keyring holding it): no Bridge connectivity, no ProofVisor code beyond this crate.
