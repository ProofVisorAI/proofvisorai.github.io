Expand description

Upper bound (inclusive) for the time field on emitted events, in milliseconds since the Unix epoch.

253_402_300_799_999 = 9999-12-31T23:59:59.999Z. The shipped schema pins time_iso to a 4-digit year via its pattern, so any time above this bound would render a 6-digit year the schema rejects. Historically the schema advertised 2^53 (JCS_SAFE_MAX) as the upper bound while the Rust validator applied this tighter year-10000 cap first — a split-brain the R51/R52 schema-drift pass closed by aligning the schema to the same bound. Exposed as a pub const so tests can pin the schema-vs-code equality (see schema_conformance.rs) and so future changes to one side without the other fail CI.
