Expand description

Serve router on listener with client-silence reaping, resolving after shutdown fires and every remaining connection drains. The caller wraps the post-shutdown tail in its own drain-budget timeout. on_accept runs synchronously per accepted socket (socket-option tuning — the caller owns its failure/log policy). The two silence bounds are parameters so tests can exercise reaping in milliseconds; production callers pass HEADER_READ_TIMEOUT / BODY_FRAME_GAP_TIMEOUT.
