Module service_binding

Expand description

Cloud-platform service binding discovery.

Discovers ProofVisor connection parameters from Cloud Foundry VCAP_SERVICES or from Kubernetes-style service binding files.

Activated by the service-binding cargo feature. Not compiled into production artifacts by default. This is client discovery metadata; the gateway does not use a binding to configure its own identity validator.
