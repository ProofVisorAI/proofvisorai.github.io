1//! In-flight context compression (brief Module C).
2//!
3//! Parses OpenAI-shape chat payloads (`messages[]` with system prompts,
4//! conversation history, and tool outputs) and applies auditable pruning
5//! passes targeting the brief's 30–50 % reduction on ≥ 50 k-token histories.
6//!
7//! Hard invariants, property-tested (never semantically destructive, D9/D13.10):
8//! 1. the first system message is byte-identical;
9//! 2. the last `keep_tail` messages are byte-identical;
10//! 3. output parses as the same shape (roles preserved, no orphaned
11//!    `tool_call_id` references);
12//! 4. idempotent: `compress(compress(x)) == compress(x)`;
13//! 5. output token count ≤ input token count.
14//!
15//! Every pruned block leaves an audit stub `[pruned: N tokens, sha256:…]` so a
16//! reviewer can prove what was removed. When a marker key is configured the
17//! stub also carries a keyed HMAC tag, so user text that merely quotes the
18//! stub shape cannot impersonate one. Metrics mirror ATIF field names.
19
20pub mod marker;
21pub mod passes;
