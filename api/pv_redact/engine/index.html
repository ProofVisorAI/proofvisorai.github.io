MAX_PATTERN_BYTES
Longest pattern compile_pattern accepts, in bytes. Long enough for every recommended redaction pattern several times over; short enough that a pattern pushed from a console cannot be a program.
PATTERN_DFA_SIZE_LIMIT

PATTERN_NEST_LIMIT

PATTERN_SIZE_LIMIT
Cap on the compiled size of one pattern (the regex crate’s default is 10 MiB; one pattern of a few hundred bytes never needs that).

Functions§

compile_pattern
Compile one operator-supplied pattern under the bounds every operator-supplied pattern gets: MAX_PATTERN_BYTES, PATTERN_SIZE_LIMIT, PATTERN_DFA_SIZE_LIMIT and PATTERN_NEST_LIMIT. The redaction engine compiles redaction_patterns this way, and console-pushed guardrail patterns reuse it, so the two cannot drift apart. Matching stays linear in the input, as with every regex-crate pattern.
