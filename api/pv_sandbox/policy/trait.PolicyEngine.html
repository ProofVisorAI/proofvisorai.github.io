Expand description

A policy engine evaluates (tool, arguments) → decision. Engines must be total: any internal failure is a Deny (fail-closed), never a panic.

fn evaluate_with_judge( &self, tool: &str, arguments: &Value, judge: &[JudgeOutcome], ) -> PolicyDecision

Evaluate a tool call together with the semantic judge’s outcomes for it (empty when the tool is not judged). Engines that do not read verdicts keep the default, which ignores them.

Source

fn sees_judge(&self) -> bool

True when this engine reads judge outcomes (and may therefore apply its own thresholds to them).
