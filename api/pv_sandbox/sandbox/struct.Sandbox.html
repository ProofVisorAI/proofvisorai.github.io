pub fn check_with_principal( &self, store: &dyn StateStore, session: &str, principal: Option<(&str, &BudgetSpec)>, raw: &[u8], ) -> ToolVerdict

Same as Self::check but layers a principal-scoped budget check on top of the session-scoped one. When principal is Some(spec), the tool call is refused unless BOTH ledgers admit the spend; the principal ledger persists across every session belonging to the same identity, which is what makes header-rotation attacks (resetting the session bucket by minting a new session id) visible.

The two ledgers commit independently: if the principal check passes and the session check fails, the principal debit is refunded on the same dimensions before returning. Both budgets must use identical BudgetSpec shapes so the refund is exact.

Source

pub fn precheck(&self, raw: &[u8]) -> Result<ValidatedCall, ToolVerdict>

Gates 1 and 2: parse the JSON-RPC envelope and validate the arguments against the local and console-pushed schemas. Returns the validated call, or the blocking verdict.

Together with Self::admit this is Self::check_with_principal split at the point where the semantic judge runs: the judge only ever sees arguments that passed the schema gate. The validated call carries the console-pushed rule snapshot this precheck used, so both halves of one call see the same bundle.

Source

pub fn admit( &self, store: &dyn StateStore, session: &str, principal: Option<(&str, &BudgetSpec)>, call: ValidatedCall, judge: Option<&JudgeEvidence>, ) -> ToolVerdict

Gates 3 and 4 for a call that passed Self::precheck: the policy chain (which sees judge’s outcomes), the judge thresholds, the console-pushed rules, and the budget. The verdict’s elapsed_us is sandbox time only (precheck plus this); time spent waiting for the judge is recorded separately.

Source

pub fn policy_verdict( &self, call: &ValidatedCall, judge: Option<&JudgeEvidence>, ) -> Option<ToolVerdict>

The policy gates alone, without spending budget: the verdict Self::admit would return before the budget gate, or None when every policy gate passes. Shadow mode uses it to compute what the judge WOULD have done.
