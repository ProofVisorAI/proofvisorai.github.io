pv_compress

Module marker

Expand description

Keyed authentication tags for machine-emitted compression stubs.

Every pruning pass leaves an audit stub so a reviewer can prove what was removed. The stub shape is a plain string, so without authentication any message whose text happens to look like a stub could impersonate one — and the middle-history pass treats “a stub is already present” as a reason to skip. This module signs each stub with an HMAC under a key derived from the journal key, so only the gateway can mint a real stub.

The tag covers the stub body (which already commits to the pruned content through its SHA-256), so a tag cannot be moved from one stub to another. Verification needs only the stub text; the original content is already gone.
